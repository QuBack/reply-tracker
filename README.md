# Роза — сбор коммерческих предложений

Программа для Windows: ищет поставщиков, рассылает им запросы через Mail.ru,
собирает ответы с файлами и делает сводную таблицу по счетам.

## Установка

Нужно один раз на каждом компьютере.

**1. Python 3.11 или новее.** В PowerShell:

```powershell
winget install Python.Python.3.12
```

Или скачайте с [python.org](https://www.python.org/downloads/) и при установке
поставьте галочку **Add python.exe to PATH**.

**2. Программа.** Скачайте проект (**Code → Download ZIP** на GitHub или
`git clone`), распакуйте и дважды щёлкните **`install.bat`**.

**3. Codex — только для поиска поставщиков.** Без него работает всё остальное.

```powershell
winget install OpenJS.NodeJS.LTS
npm install -g @openai/codex
codex login
```

`codex login` откроет браузер: войдите в свой аккаунт ChatGPT (подойдёт
подписка Plus). Проверка: `codex login status` должно показать
`Logged in using ChatGPT`. Если у вас уже стоит приложение Codex для Windows,
этот шаг можно пропустить: программа найдёт его сама.

## Запуск

Двойной щелчок по **`run.bat`**.

При первом запуске откройте вкладку **Настройки**, укажите почту Mail.ru и
**пароль для внешних приложений**: Mail.ru → Настройки → Безопасность → Пароли
для внешних приложений. Обычный пароль от почты не подойдёт.

## Данные

База, письма и вложения хранятся не в папке проекта, а в
`%LOCALAPPDATA%\RosaMailCollector`. Обновление программы их не затрагивает.
Чтобы перенести данные на другой компьютер, скопируйте эту папку.

## Если что-то не так

| Проблема | Что сделать |
|---|---|
| `python` не найден | Переустановите Python с галочкой **Add to PATH**, откройте новое окно |
| «Codex CLI не найден» | Выполните шаг 3, затем перезапустите программу |
| «Codex не завершил поиск» | `codex login`, проверьте, что не кончились лимиты Codex |
| Поиск нашёл 0 компаний | Опишите товар подробнее, укажите регион |

## Для разработчика

- Тесты: `python -m unittest discover -s tests`
- Собрать `RosaMail.exe`: `build_exe.bat`, результат появится в `outputs\`
- Модель и уровень рассуждений для поиска задаются в
  `rosa_mail/supplier_search.py` (`SEARCH_MODEL`, `REASONING_EFFORT`)
- Подробное руководство: [docs/ПОДРОБНО.md](docs/ПОДРОБНО.md)
