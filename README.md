# Система автоматизации

Программа для Windows: ищет поставщиков, рассылает им запросы по почте,
собирает ответы с вложениями и делает сводную таблицу по полученным счетам.

## Установка и запуск

1. Скачайте проект: на GitHub **Code → Download ZIP**, затем распакуйте архив.
2. Дважды щёлкните **`start.bat`** и дождитесь окончания.

`start.bat` сам установит всё недостающее:
- Python;
- библиотеки;
- Node.js и Codex для поиска поставщиков.

Затем он откроет программу. Если Windows спросит разрешение на установку,
нажмите «Да». Первый запуск займёт несколько минут, следующие — пару секунд.
Дальше программу запускайте тем же `start.bat`.

Один раз `start.bat` попросит войти в **Codex**. Откроется браузер: войдите в
свой аккаунт ChatGPT, подойдёт подписка Plus, и вернитесь в окно. Без Codex
работает всё, кроме поиска поставщиков.

## Первая настройка

Откройте вкладку **Настройки**, выберите почтовый сервис и укажите адрес и пароль:

- **Mail.ru** — нужен **пароль для внешних приложений**. Его создают в Mail.ru:
  Настройки → Безопасность → Пароли для внешних приложений. Обычный пароль от
  почты не подойдёт.
- **Timeweb** — полный адрес ящика (`name@вашдомен.ru`) и обычный пароль от
  ящика.

Пароль хранится в диспетчере учётных данных Windows.

## Где данные

База, письма и вложения лежат в `%LOCALAPPDATA%\AutomationSystem`, отдельно
от папки программы. Если программа уже стояла раньше, она продолжит работать
в своей прежней папке данных. Обновление программы данные не затрагивает.
Чтобы перенести данные на другой компьютер, скопируйте эту папку.

## Если что-то не так

| Проблема | Что сделать |
|---|---|
| `start.bat` не смог поставить Python | Установите с [python.org](https://www.python.org/downloads/) с галочкой **Add python.exe to PATH** и запустите `start.bat` снова |
| «Codex CLI не найден» | Запустите `start.bat` ещё раз или поставите вручную: `npm install -g --include=optional @openai/codex`, затем `codex login` |
| «Codex не завершил поиск» | Выполните `codex login`, проверьте, не кончились ли лимиты Codex |
| Поиск нашёл 0 компаний | Опишите товар подробнее, укажите регион |

## Для разработчика

- Тесты: `python -m unittest discover -s tests`
- Собрать `Automation.exe`: `build_exe.bat`, результат появится в `outputs\`
- Модель и уровень рассуждений для поиска задаются в
  `automation/supplier_search.py` (`SEARCH_MODEL`, `REASONING_EFFORT`)
- Подробное руководство: [docs/ПОДРОБНО.md](docs/ПОДРОБНО.md)
